# Holberton School - Higher Level Programming Projects

## Overview

This repository contains the collection of my **Holberton School Higher Level Programming projects**. The curriculum is focused on **advanced programming concepts** across multiple languages, including **SQL, JavaScript, and Python**, covering foundational and practical skills for real-world software development.

The repository is organized by language and topic, with individual directories containing specific exercises and projects.

---

## Learning Focus

The projects in this repository cover:

* SQL: database queries, data manipulation, and relational concepts
* JavaScript: DOM manipulation, basic scripts, and client-side logic
* Python: object-oriented programming, data structures, serialization, TDD, server-side rendering, and RESTful API development

The curriculum emphasizes:

* Problem-solving and algorithmic thinking
* Clean, maintainable, and testable code
* Working with different data sources (JSON, CSV, SQLite, MySQL)
* Practical application of programming principles
