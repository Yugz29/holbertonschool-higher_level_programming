# JavaScript Warm Up

## Overview

This directory contains beginner JavaScript exercises from the **Higher Level Programming** track of the Holberton School curriculum.

The exercises focus on building fundamental skills in JavaScript, covering basic syntax, functions, loops, arrays, objects, and simple algorithmic logic. They are designed to provide a solid foundation before moving on to more advanced topics like DOM manipulation or asynchronous JavaScript.

---

## Learning Focus

This module demonstrates how to:

* Write basic JavaScript syntax and output
* Use variables (`let`, `const`) and basic types
* Write reusable functions
* Apply control flow with `if`, `else`, and loops
* Manipulate arrays and objects
* Work with function arguments
* Solve simple algorithmic problems (factorials, summations, etc.)

## Example Snippet

Example of a simple function with arguments:

```javascript
function add(a, b) {
  return a + b;
}

console.log(add(3, 5)); // Outputs 8
```

This snippet demonstrates defining a function, passing arguments, and displaying the result.
